Judul Studi Kasus
Analisis Pola Perilaku Pelanggan & Prediksi Tren Menggunakan Exploratory Data Analysis (EDA) dan Machine Learning Sederhana
Skenario & Latar Belakang
Sebagai seorang data analyst di sebuah perusahaan ritel/teknologi, kamu diminta untuk "membuat data berbicara" (make sense of data). Perusahaan memiliki data transaksi/pelanggan yang kotor dan belum terstruktur. Tugasmu adalah membersihkan data, menemukan wawasan (insights) tersembunyi melalui visualisasi dan analisis statistik, lalu menerapkan model AI/Machine Learning dasar untuk memprediksi kategori atau pola tertentu.

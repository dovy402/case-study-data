Skenario & Latar Belakang

Perusahaan memiliki data transaksi/pelanggan yang kotor dan belum terstruktur. Tugasmu adalah membersihkan data, menemukan wawasan (insights) tersembunyi melalui visualisasi dan analisis statistik, lalu menerapkan model AI/Machine Learning dasar untuk memprediksi kategori atau pola tertentu.
